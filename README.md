# Finance Application

This is a simple finance and accounting web application built with the Laravel framework. It allows basic management of accounts and their transactions.

## Features

- Create and list accounts
- Record transactions for each account

## Installation

1. Install PHP dependencies:
   ```bash
   composer install
   ```
2. Copy `.env.example` to `.env` and configure your database.
3. Run database migrations:
   ```bash
   php artisan migrate
   ```
4. Serve the application locally:
   ```bash
   php artisan serve
   ```
